# Research agenda

## Central question
**Can an administrative helpdesk separate routine operations from obvious emergency escalation without attempting clinical reasoning?**

## Hypotheses
### H1
An explicit emergency short-circuit prevents clearly urgent text from being treated as routine administration.

### H2
Reference requirements reduce accidental handling of underspecified records/billing requests.

### H3
A narrow administrative taxonomy produces more defensible behavior than an unconstrained medical chatbot.

## Experiments
1. Create a synthetic admin corpus with routine, underspecified, unknown, and clearly urgent messages.
2. Measure phrase-screen sensitivity to paraphrases and document its limitations.
3. Compare constrained routing with a future intent classifier while preserving the clinical boundary.

## Metrics
- administrative routing accuracy
- missing-reference detection
- emergency escalation recall on defined phrase set
- false emergency escalation
- unknown-category abstention
